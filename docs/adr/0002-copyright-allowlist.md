# ADR-0002: 저작권은 허용 목록으로, 좌표는 퍼블릭 도메인·CC0로만

- 상태: 채택
- 날짜: 2026-11-07 (그동안의 결정을 모아 적음)
- 관련: CLAUDE.md 0장

## 배경

교육용·비상업 앱이지만 공개 배포한다. 6·25 자료는 기관·언론·블로그에 흩어져 있고 이용 조건이 제각각이다. 하나씩 판단하면 실수가 생긴다.

## 결정

- 이미지는 **허용 목록**(퍼블릭 도메인, CC0, CC BY, CC BY-SA, 공공누리 제1유형)만 쓰고, 목록 밖은 쓰지 않는다. 비상업(NC)·변경 금지(ND)·통신사 사진은 커먼즈에 있어도 쓰지 않는다.
- 원본 페이지에서 라이선스를 직접 확인하고 메타데이터를 남긴다. 적재기가 목록 밖 라이선스를 찾으면 앱이 뜨지 않는다.
- 글은 사실만 가져와 우리 문장으로 쓴다. 나무위키·뉴스·블로그는 사실 확인에도 쓰지 않는다(이야기 화면만 공식 발표·뉴스를 사실 확인에 허용).
- 좌표는 Natural Earth(퍼블릭 도메인)·위키데이터(CC0)·미군 지도(AMS, 퍼블릭 도메인)에서 온 값만 저장소에 넣는다. GeoNames·위키백과·OSM은 대조용.
- 지도 타일·외부 글꼴 서버는 쓰지 않는다(지금의 군사분계선·지명이 1950년대 전선과 섞인다).

## 검토한 대안

| 대안 | 장점 | 단점 |
| --- | --- | --- |
| 비상업 조건 자료도 쓰기 | 자료가 훨씬 많다 | 배포 형태가 바뀌면(후원, 광고) 바로 문제가 된다 |
| 건마다 판단 | 유연하다 | 기준이 흔들리고 검수가 어렵다 |

## 결과

- 사진이 없는 인물·국기가 생긴다(이름 첫 글자로 보인다). 김일성·마오쩌둥 사진, 교황청 당시 국기 등.
- 새 자료를 넣을 때 할 일이 정해져 있어 검수가 빠르다.
