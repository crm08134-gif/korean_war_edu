# ADR-0004: 게시판은 사건·인물 두 개, 신고 2명이면 자동 가림

- 상태: 채택
- 날짜: 2026-11-07 (2026-11-01·03 결정을 모아 적음)
- 관련: CLAUDE.md 7장, V12·V13

## 배경

자유게시판은 주제가 흩어지고 관리가 어렵다. 운영자가 한 명이라 신고를 바로 보지 못할 때도 문제 글이 오래 남지 않아야 한다.

## 결정

- 하단 패널 "게시판" 탭 안에 사건 게시판·인물 게시판. 글은 `board` + 대상 id(대상 테이블은 적재기가 다시 채우므로 외래 키 없음).
- 서로 다른 회원 2명이 신고하면 자동으로 가린다. 관리자 큐에서 되살리거나 가린다. 신고할 때 대상 행을 잠가 2명을 정확히 센다.
- 가려진 본인 글은 "기타" 신고로 재검토를 요청할 수 있다(이의 제기).
- `/api/admin/**`은 토큰의 ADMIN과 DB 역할을 함께 확인한다.

## 검토한 대안

| 대안 | 장점 | 단점 |
| --- | --- | --- |
| 자유게시판 | 쓰기 쉽다 | 주제가 흩어지고 관리가 어렵다 |
| 관리자만 가림 | 오용이 없다 | 운영자가 볼 때까지 글이 남는다 |
| 기준 3명 이상 | 혼자 가리기 어렵다 | 이용자가 적을 때 가려지지 않는다 |

## 결과

- 한 사람이 두 계정(카카오·구글)으로 혼자 가릴 수 있다. 악용되면 기준을 올리거나 가입 직후 계정의 신고를 세지 않는다.
