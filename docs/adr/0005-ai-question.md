# ADR-0005: AI 질문은 카드마다, 카드는 맥락으로만, 대화는 저장하지 않음

- 상태: 채택
- 날짜: 2026-11-07 (2026-11-05 결정을 모아 적음)
- 관련: CLAUDE.md 8장, V15, #67·#68

## 배경

카드를 읽고 더 궁금한 것을 바로 묻게 하고 싶다. 무료 등급(Gemini Flash)을 쓰고, 지어낸 답을 줄여야 한다.

## 결정

- 전역 챗봇 없이 사건·이야기 카드 머리말에 "AI 질문". 근거 맥락이 없는 질문은 지어낼 위험이 크다.
- 카드 내용은 서버가 DB에서 읽어 보낸다(프론트가 보낸 글은 받지 않음). 규칙: 카드는 맥락으로만 쓰고 **카드 밖 내용을 설명**, 확실하지 않은 것은 지어내지 않음, 1장의 관점 규칙, 10문장 이내, 6·25와 상관없는 질문 거절.
- 로그인 회원만, 하루 20번·전체 200번. 질문·답은 저장하지 않고 횟수만(`chat_usage`).
- 무료 등급은 구글이 내용을 학습에 쓰므로 회원 번호·닉네임은 보내지 않고 "개인정보를 적지 마세요"를 적는다.
- 답은 글자로만 보이고 "AI 답변 · 검수하지 않은 내용"을 붙인다.

## 검토한 대안

| 대안 | 장점 | 단점 |
| --- | --- | --- |
| 카드 내용만으로 답 | 지어낼 위험이 적다 | 사용자는 카드에 없는 것이 궁금해서 묻는다(#68에서 바꿈) |
| 구글 검색 연결(grounding) | 최신·근거 링크 | 링크가 1장의 쓰지 않는 자료일 수 있다. 써 본 뒤 정한다 |
| 대화 저장 | 품질 점검 | 개인정보·보관 부담 |

## 결과

- 답이 틀릴 수 있다는 것을 화면에 밝힌다. 운영 키가 없으면 503.
