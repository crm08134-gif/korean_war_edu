# ADR-0006: 참전국 숫자는 국가보훈부 표 하나, DB 없이 CSV

- 상태: 채택
- 날짜: 2026-11-07 (2026-11-05·06 결정을 모아 적음)
- 관련: CLAUDE.md 9장, #69·#71

## 배경

참전국 연인원·전사자·사상자는 자료마다 다르다. 1장 규칙(둘 다 적기)을 따르면 22개국 × 3칸이 출처마다 늘어 격자가 읽기 어려워진다.

## 결정

- 숫자는 국가보훈부 표 하나로 맞추고 출처를 화면 맨 아래에 적는다(사용자 결정, 1장 규칙의 예외).
- 전투병 16개국, 의료지원 6개국(독일 포함), 물자지원 37개국 + 의사표명 3개국.
- 데이터는 바뀔 일이 거의 없어 DB 없이 `data/countries/countries.csv`를 앱 시작 때 읽고 검사한다(`CountryCatalog`).

## 검토한 대안

| 대안 | 장점 | 단점 |
| --- | --- | --- |
| 출처마다 숫자 함께 | 1장 규칙 그대로 | 격자가 복잡해진다 |
| DB 테이블 | 다른 데이터와 같은 방식 | 마이그레이션과 적재기가 늘어난다 |

## 결과

- 숫자를 바꾸려면 CSV만 고치면 된다. 다른 자료와 차이는 화면에 드러나지 않는다.
