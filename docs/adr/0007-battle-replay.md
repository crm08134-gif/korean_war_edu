# ADR-0007: 전투 재생은 CMH 지도에서 읽은 키프레임으로, 효과 없이

- 상태: 채택
- 날짜: 2026-11-07 (2026-11-06 결정을 모아 적음)
- 관련: CLAUDE.md 4장, `docs/battle-replay.md`, #73·#74·#79~#84

## 배경

전투 카드의 글만으로는 며칠간의 이동·포위를 그리기 어렵다. 그렇다고 부대 위치를 지어내면 0장의 "좌표를 지어내지 않는다"를 어긴다.

## 결정

- 부대 위치·화살표·전선 조각은 **CMH 전사의 지도**(퍼블릭 도메인)에서만 읽는다. 지도의 날짜(하루짜리는 시각)를 키프레임으로 두고 사이는 보간한다.
- 지도를 경위도로 맞출 기준점은 미군 지도(AMS, 도쿄 측지계를 WGS84로 바꿈)나 위키데이터에서 가져오고, LOO 오차를 기록한다(`data/battles/sources/`).
- 데이터는 DB 없이 `data/battles/<사건 id>.json`을 앱 시작 때 읽고 검사한다(`BattleCatalog`).
- 연대급까지(예외: 대대급 전투, 따로 표시된 참전국 부대), 아이콘 10개 안팎. 폭발·흔들림 같은 효과는 넣지 않는다(데모 후 사용자 결정). 공격·이동은 지도의 화살표로.
- 근거 지도에 전선이 없으면 스냅샷 전선을 감춘다(`showFront`). 지명 이름표(`places`), 아이콘 겹침은 위아래로 비켜 놓는다.

## 검토한 대안

| 대안 | 장점 | 단점 |
| --- | --- | --- |
| 글을 보고 위치 추정 | 전투를 더 많이 만들 수 있다 | 좌표를 지어내게 된다 |
| 한국 측 지도(군사편찬연구소) | 한국 부대가 자세하다 | 이용 조건이 "all rights reserved" |
| 교전·폭발 효과 | 볼거리가 는다 | 기록 톤과 맞지 않는다 |

## 결과

- 근거 지도가 없는 전투는 만들 수 없다(백마고지). 지도가 한 장뿐이면 키프레임이 둘뿐이다(지평리).
- 전투를 더할 때마다 `docs/battle-replay.md` 3장 순서를 따른다.
