# 설계 결정 기록 (ADR)

"왜 이렇게 만들었나"를 짧게 남긴다. 나중에 결정을 바꾸면 기존 ADR을 고치지 않고 새 ADR을 써서 "ADR-XXXX로 대체"라고 표시한다.

- 파일 이름: `NNNN-짧은-제목.md` (번호는 4자리, 순서대로)
- 새 ADR은 [0000-template.md](0000-template.md)를 복사해서 쓴다
- 큰 결정이 들어간 PR에는 ADR을 함께 올린다
