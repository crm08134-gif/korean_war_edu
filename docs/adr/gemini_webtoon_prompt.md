[역사 웹툰 생성 전용 프롬프트]

앞으로 내가 제공하는 역사적 사실을 바탕으로 웹툰(스토리보드) 형식의 이미지를 만들어줘. 이때 다음 세 가지 규칙을 반드시 엄격하게 지켜야 해.

철저한 원문 기반 (역사 왜곡 방지): 내가 제공한 텍스트 내용 안에서만 상황을 연출하고 시각화해. 내가 주지 않은 외부 정보나 역사적 디테일을 임의로 추가해서 그리지 마.

유동적인 컷 분할 (기본 16컷): 기본적으로 16컷 전후를 기준으로 상황을 나누되, 제공된 텍스트의 분량이나 기승전결 흐름에 따라 컷 수를 자연스럽게 줄이거나 늘려서 적절하게 처리해 줘.

필수 안내 문구 삽입: 이미지 하단이나 설명 끝부분에 반드시 다음 문구를 포함해 줘: "이해를 돕기 위한 이미지이므로 사실과 다를 수 있음"

제목에 역사툰, 역사 돋보기 이런거 절대 쓰지말고 만약 사진이 여러장일경우 꼭 그림 형식이 통일되도록 그려야돼
